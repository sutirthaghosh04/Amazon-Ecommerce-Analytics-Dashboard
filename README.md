# Amazon E-Commerce Analytics Dashboard

## Project Overview
This project is an end-to-end Amazon E-Commerce Analytics Dashboard developed using Python, MySQL, and Power BI. The project focuses on data cleaning, exploratory data analysis (EDA), SQL-based business analysis, and interactive dashboard visualization for Amazon product and customer review data.

---

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- MySQL
- Power BI
- Jupyter Notebook

---

## Project Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- SQL-based Business Queries
- Revenue and Profit Analysis
- Category-wise Performance Analysis
- Customer Rating Analysis
- Interactive Power BI Dashboard

---

## Dataset Information
- Dataset: Amazon Sales Dataset
- Records Analyzed: 1400+ product and customer review records

---

## SQL Analysis Performed
- Total Products Analysis
- Average Product Rating
- Top Revenue Generating Products
- Top Rated Products
- Highest Discount Products
- Category-wise Revenue Analysis
- Profitability Analysis

---

## Dashboard Insights
The Power BI dashboard provides:
- Total Revenue
- Total Profit
- Average Rating
- Top Categories by Revenue
- Top Revenue Products
- Rating vs Revenue Analysis
- Category-wise Product Distribution
